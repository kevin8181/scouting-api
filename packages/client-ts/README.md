# @scouting-api/client

**Unofficial TypeScript client for Scouting America APIs, generated from the [scouting-api](https://github.com/kevin8181/scouting-api) specs.**

> [!NOTE]
> This project is not affiliated with or endorsed by Scouting America. The client is generated from specs that describe what the APIs actually do, observed by calling them, and may lag behind changes to the APIs.

## Install

```sh
npm install @scouting-api/client
```

| API                             | Docs                                                                            |

| `scoutconnect-api.scouting.org` | [Docs](https://kevin8181.github.io/scouting-api/scoutconnect-api.scouting.org/) |

## Contributing

The client is generated from the specs, so a wrong field or missing endpoint is fixed in the spec. Issues and pull requests are welcome in the [scouting-api repo](https://github.com/kevin8181/scouting-api).
